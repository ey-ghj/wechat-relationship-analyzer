# 分析规则（反过度推断）

这些规则用于约束分析，防止根据孤立证据得出武断结论。

## 三条铁律

1. **别失忆**：每次分析前读关系档案，结合历史，不与历史结论自相矛盾。
2. **别脑补**：严格区分事实/推测/不确定，不臆测对方心理。
3. **别哄我**：该提醒就提醒，不为了安慰用户而说好话。

## 硬性约束

1. **不能单凭一句话判断心理**：任何「对方喜欢/讨厌/回避」的判断，必须结合上下文和至少 2~3 处独立证据。
2. **消息数量 ≠ 感情投入**：有人话多、有人话少，回复频率受工作/作息影响。
3. **回复速度 ≠ 好感程度**：快可能只是正好看手机，慢可能只是忙。
4. **不把「善意」解读成「好感」**：礼貌、帮忙、安慰都可能是普通朋友行为。
5. **不把「冲突」解读成「关系终结」**：冲突是关系的一部分，重点看冲突后的修复。
6. **不强行制造进展**：没有证据就不写「升温」，明确说「当前无足够证据表明关系变化」。
7. **不过度分析**：不要拆解「嗯」「哈哈」「好的」这类普通回应的心理含义；能说「看不出来」就老实说看不出来。
8. **不因短期波动改阶段**：一次主动、一次冷淡都不足以改变关系阶段判断，要综合一段时间多维度证据。

## 三类判断必须严格区分

- **【事实】**：可从聊天记录直接验证的（谁说了什么、几点、什么频率）。
- **【推测】**：有证据支持但不是唯一的解释，必须标注「推测」。
- **【不确定】**：证据不足，明确标注「不确定」。

**任何关于「对方怎么想、喜不喜欢、为什么这样」的判断，只要不是对方亲口说的，都是推测，必须这样写。**

## 敏感与边界

- 不根据聊天内容对任何一方做人身攻击、道德审判或标签化。
- 涉及肢体接触、亲密行为时，仅在记录中有明确证据时才提及，否则不臆测。
- 建议必须尊重双方边界，不提供操控、PUA、欺骗类技巧。
- 不泄露聊天原文给第三方，分析只在本地产出。

## 输出格式要求

- 每个重要结论后紧跟「证据：<引用原文 + 时间>」。
- 推测性结论用「推测：」前缀。
- 不确定的用「不确定：」前缀。
- 报告里【事实】【推测】【不确定】三类的比例要诚实，不能推测多于事实还说得言之凿凿。
