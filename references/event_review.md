# 关键事件复盘指南

对关系中的关键事件（首次邀约、冲突、冷淡、升温转折等）做复盘，理解背景、我的行为、对方反应、后续变化与对关系的影响。

复盘不只是记录结果，而是理解**这件事为什么会发生、我做了什么、对方怎么接、之后往哪走了**。

## 复盘五要素

1. **背景**：事件发生前，双方处于什么状态？之前聊了什么、氛围如何？
   - 用 `events.py review --datetime <事件时间> --before 20 --after 20` 取事件前后上下文。
2. **我的行为**：我当时做了什么、说了什么？（客观描述，不美化、不辩解）
3. **对方的反应**：对方怎么回应？情绪如何？（结合原文，不臆测心理）
4. **后续变化**：事件后，双方的行动、互动频率、态度有什么变化？
5. **对关系的影响**：这件事是升温、维持还是降温的转折点？对后续关系产生了什么实际影响？

## 复盘输出结构

```
事件：<类型> @ <时间>
背景：<事件前双方状态 + 证据>
我的行为：<我当时做了什么 + 原文>
对方的反应：<对方回应 + 原文 + 情绪判断>
后续变化：<事件后的互动变化 + 证据>
对关系的影响：<升温/维持/降温 + 判断依据>
教训/建议：<我哪里做得好/不好 + 下次怎么改进>
```

## 规则

- 每个判断都引用原文 + 时间。
- 情绪判断标注【事实】/【推测】/【不确定】。
- 不因为一次冲突就断定关系恶化，要看冲突后的修复。
- 复盘结论写入 `profile.json` 的 `key_events`，包含 `background`、`my_action`、`their_reaction`、`follow_up`、`impact` 字段。
- 对「我的行为」的评价要客观：做得好就说好，做得不合适就直接指出来，不护短。
