# 关键事件复盘指南

对关系中的关键事件（首次邀约、冲突、冷淡、升温转折等）做复盘，理解背景、反应、后续与关系变化。

## 复盘四问

1. **背景**：事件发生前，双方处于什么状态？之前聊了什么、氛围如何？
   - 用 `events.py review --datetime <事件时间> --before 20 --after 20` 取事件前后上下文。
2. **双方反应**：事件中，双方各自说了什么？情绪如何？（结合原文，不臆测）
3. **后续行动**：事件后，双方做了什么？关系往哪个方向走了？
4. **关系变化**：这个事件是升温、维持还是降温的转折点？

## 复盘输出结构

```
事件：<类型> @ <时间>
背景：<事件前双方状态 + 证据>
双方反应：<各自的原话 + 情绪判断>
后续行动：<事件后的行动 + 证据>
关系变化：<升温/维持/降温 + 判断依据>
教训/建议：<结合复盘给出的下一步建议>
```

## 规则

- 每个判断都要引用原文 + 时间。
- 情绪判断要标注【事实】/【推测】/【不确定】。
- 不因为一次冲突就断定关系恶化，要看冲突后的修复。
- 复盘结论写入 `profile.json` 的 `key_events`（含 `analysis` 和 `outcome` 字段）。
