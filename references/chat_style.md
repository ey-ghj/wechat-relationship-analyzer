# 个人聊天风格档案

让 AI 回复贴合用户平时表达习惯，目标是**像用户自己会说的话**，不是客服话术，也不是 AI 味。

## 风格档案来源

- `data/style.json`：`style.py` 产出的客观风格指标（见下）
- `data/profile.json` 的 `chat_style`：LLM 在分析中沉淀的风格描述

## 客观风格指标（style.py）

| 指标 | 含义 | 用途 |
|---|---|---|
| `avg_text_length` | 平均文本长度 | 判断说话长短习惯（话少别给长篇） |
| `emoji_ratio` / `image_ratio` | 表情/图片占比 | 判断是否爱发表情图 |
| `punct_per_100_text` | 每百条文本的标点次数（？/！/。） | 判断语气强烈程度 |
| `common_phrases` | 高频 2~3 字短语（口头禅） | 让回复自然融入用户常用词 |
| `time_slots` | 时段分布 | 判断活跃时段 |
| `message_types` | 消息类型分布 | 判断沟通形式偏好 |

## 主观风格维度（LLM 在分析中沉淀到 chat_style）

除了客观指标，还要观察并记录：

1. **用词习惯**：常用语气词（啊/哦/吧/咯）、口头禅、称呼对方的方式。
2. **语气基调**：偏轻松/认真/调侃/简短直接。
3. **句子长度**：爱短句连发，还是长篇大段。
4. **表情包与幽默**：是否爱用表情、爱开玩笑、幽默风格（自嘲/吐槽/俏皮）。
5. **标点与节奏**：爱用感叹号/问号，还是不加标点。

## 使用规则

1. **生成回复前必须读风格档案**，参考用户的平均长度、口头禅、语气、幽默习惯。
2. **不改变用户的性格**：话少别给长篇；不爱发表情别硬配。
3. **不套模板**：结合当前语境 + 用户风格给建议，可只给 1 个，不必每次堆选项。
4. **风格描述持续累积**：每次分析发现新的风格特征，更新 `profile.json` 的 `chat_style`。
5. **避免**：过度热情、刻意讨好、施加压力、客服腔、书面化、AI 味。
