# 个人聊天风格档案

让 AI 回复贴合用户平时表达习惯，避免 AI 味、过度热情、刻意讨好。

## 风格档案来源

- `data/style.json`：`style.py` 产出的客观风格指标（见下）
- `data/profile.json` 的 `chat_style`：LLM 在分析中沉淀的风格描述（如「语气轻松、爱用语气词」）

## 客观风格指标（style.py）

| 指标 | 含义 | 用途 |
|---|---|---|
| `avg_text_length` | 平均文本长度 | 判断用户说话长短习惯 |
| `emoji_ratio` / `image_ratio` | 表情/图片占比 | 判断是否爱发表情图 |
| `punct_per_100_text` | 每百条文本的标点次数（？/！/。） | 判断语气强烈程度 |
| `common_phrases` | 高频 2~3 字短语（口头禅） | 让回复自然融入用户常用词 |
| `time_slots` | 时段分布（上午/下午/晚上/深夜） | 判断活跃时段 |
| `message_types` | 消息类型分布 | 判断沟通形式偏好 |

## 使用规则

1. **生成回复前必须读风格档案**，参考用户的平均长度、口头禅、语气习惯。
2. **不改变用户的性格**：话少的用户别给长篇回复建议；爱发表情的可以适当配表情。
3. **不套模板**：结合当前对话语境 + 用户风格，给 2~3 个自然回复选项。
4. **风格描述（tone_notes）由 LLM 沉淀**，写入 `profile.json` 的 `chat_style`，持续累积。
5. **避免**：过度热情、刻意讨好、施加压力、AI 味的书面腔。
