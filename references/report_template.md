# 分析报告模板

每次分析按此结构输出。所有结论必须带证据（聊天原文 + 时间）。

## A. 当前关系状态

- **当前关系阶段**：<阶段名 / 过渡中 / 不确定>
- **判断依据**：<引用 2~3 条关键聊天原文>
- **可信度**：<高 / 中 / 低，说明原因>
- **双方互动特点**：<简要概括，如「一方主动分享，一方回应积极」>

## B. 最近聊天分析

- **双方主动程度**：<谁更主动开启话题，用 topic_initiations 数据>
- **互动质量**：<回复是否深入、是否接话、是否敷衍>
- **情绪变化**：<升温 / 平稳 / 降温，证据>
- **值得关注的对话**：<列出 1~3 段关键对话原文>

## C. 关键证据

每个结论引用原文，并标注：
- 【事实】可直接验证的
- 【推测】有依据但非唯一解释
- 【不确定】证据不足

## D. 关系趋势

- 与上一阶段对比的变化
- 升温 / 稳定 / 停滞 / 降温
- 重要转折点（时间 + 事件 + 证据）

## E. 下一步建议

- 是否适合主动联系
- 是否适合邀约
- 是否需要给对方空间
- 是否需要解释或道歉
- 如何尊重边界、自然推进

建议必须贴合真实语境，不使用套路化操控技巧。

## F. 消息回复辅助（可选，用户提供最新对话时）

- 理解上下文与氛围
- 给出 2~3 个自然回复选项，各附理由
- 保留用户原聊天风格，不过度热情、不施加压力
